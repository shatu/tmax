# `sft/` — Supervised Fine-Tuning stack

This directory turns raw agent trajectories into a trained terminal-agent model
in **three stages**: conversion → pre-tokenization → training.

> **The full guide lives in [`../docs/sft.md`](../docs/sft.md)** (the repo
> `docs/` folder). Read that first — it has the schema, every script, the harness
> system, the rl_data → SFT link, the DeepSpeed Ulysses SP training setup, an
> end-to-end example, and gotchas. This README is just the in-folder map.

## Layout

```
sft/
├── preprocessing/      # raw trajectories -> unified SFT parquet (Stage 1)
│   ├── pipeline.py             # orchestrator over sources.yaml (terminus2 / sera / passthrough)
│   ├── convert.py              # Terminus-2 trace -> unified messages
│   ├── convert_sera.py         # Sera SWE-agent trace -> unified messages (bash-only)
│   ├── convert_trajectories.py # rl_data solve outputs (*_summary.json) -> unified messages
│   ├── harness.py              # vanillux / tassie system-prompt + instance framing
│   ├── builders.py             # tool_calls / tool_results / reasoning / submit helpers
│   ├── json_extraction.py      # 5-strategy JSON extractor for assistant turns
│   ├── filters.py              # mandatory / optional / warning quality filters
│   ├── filter_bad_tool_call.py # post-pass: drop literal "<tool_call>" rows
│   ├── report.py               # conversion reports
│   ├── config/                 # sources.yaml, tool_schemas.json, system_prompt.txt
│   └── docs/                   # historical implementation/improvement reports
├── data.py             # load converted parquet -> HF Dataset (+ tool injection)
├── pre_tokenize.py     # tokenize messages -> input_ids (+ assistant_masks)   (Stage 2)
├── train.py            # TRL SFTTrainer w/ DeepSpeed Ulysses sequence parallel (Stage 3)
├── configs/            # accelerate + deepspeed configs (sp4/sp8, 1-4 nodes)
├── scripts/            # runnable shell wrappers for every stage
└── tests/              # pytest for json_extraction / builders / convert
```

## The three stages

```
raw trajectories        unified SFT parquet         tokenized dataset       trained model
(HF Hub / rl_data)      messages|tools|source|meta  input_ids[,asst_masks]  checkpoint
       │  run_conversion*.sh    │  run_pretokenize_*.sh   │  run_sft*.sh        │
       └─► preprocessing.pipeline ─► pre_tokenize.py ──────► train.py ──────────┘
            (or convert_trajectories)  (assistant-only masks)  (TRL + Ulysses SP)
```

## Quick start

```bash
cd sft
bash scripts/run_conversion_teaser.sh            # 1% smoke test of every source
bash scripts/run_conversion.sh                   # full corpus (vanillux framing)
bash scripts/run_pretokenize_sweagent_full_qwen3.5.sh
bash scripts/run_sft_qwen3.5-4b.sh               # 8× H200, single node
```

For skill-tax data generated by the `rl_data/` pipeline, use
`scripts/run_conversion_skill_tax_sft.sh` (wraps `convert_trajectories.py`) — see
the [rl_data → SFT link](../docs/sft.md#skill-tax--rl_data-trajectories-the-link-to-the-rl_data-pipeline).

**Everything else — flags, defaults, schema, training internals — is in
[`../docs/sft.md`](../docs/sft.md).**
